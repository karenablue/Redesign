# Chapter import completed

Updated September 18, 2026. All 305 remaining listings with assigned regions have
been added to the locator, bringing the collection to 719 listings. The five
previously added chapters (Zeta, Theta, Xi, Phi, Omicron) remain included.

No records with assigned regions remain missing from the Wikipedia-active audit.
The CSV now contains only the two records excluded at the user's request:

- Gamma Alpha — Monrovia, Liberia: regional assignment unresolved.
- Kappa Beta — institution listed as “Bakers,” with no location.

Wikipedia-sourced entries retain their reference URL and status notes internally. Public cards
link to their regional directories without source/status commentary.
Regional assignments follow published geographic boundaries regardless of
whether a chapter has an individual website link. Existing regional listings
retain their source information. Wikipedia's Inactive and Reissued rows were
not part of this audit. Multiple published listings with the same chapter name
and different campuses/locations remain separate; totals count listings.
Existing records with conflicting campus/location details are not reconciled here.
